[NOTES for GPIO]
{Strapping Pins}-----There are four Strapping Pins for ESP32-S3: GPIO00, GPIO45,GPIO46,GPIO3
With the release of the chip's system reset(power-on reset, RTC watchdog reset, undervoltage reset), the strapping pins sample the level and store it
in the latch as "0" or "1", and keep it until the chip is powerd off or turned off.

Each Strapping Pin is conneting to an internal pull-up/pull-down. Conneceting to high-impedance external circuit or without an external connection, a strapping pin's
default value of input level will be determined by interal weak pull-up/pull-down.
To change the value of the strapping, users can apply an external pull-down/pull-up resistor, or use the GPIO of the host MCU to control the level of the strapping pin
when the ESP32-S3's power on reset is released.

When releasing the reset, the strapping pin has the same function as a normal pin.
By default, the ROM boot messages are printed over UART0(U0TXD pin) and USB Serial/JTAG controller together.
The ROM code printing can be disabled through configuraiton register and eFUSE. {ESP32-S3 Technical Reference Manual}

[PSRAM Pin]
The module on the ESP32-S3-WROOM board use the ESP32-S3R8 chip with 8MB of external flash.
When we use the OPI PSRAM, please note that the GPIO35-GPIO38 on the ESP32-S3-WROOM board will not be available for other purposes. When OPI PSRAM is not used, GPIO35-GPIO37 on the board
can be used as normal GPIO.

[SDcard pin]
An SD card slot is integrated on the back of the ESP32-S3-WROOM board. We can use GPIO38-GPIO40 of ESP32-S3-WROOM to drive SD card.
The SDcard of ESP32-S3-WROOm uses SDMMC, a 1-bit bus driving method, which has been integrated in the Arduino IDE, and we call the "SD_MMC.h" library to drive it.
For details see the SDcard chapter!!!

[USB Pin]
In Micropython, GPIO19 and GPIO 20 are used for the USB function of ESP32S3, so they cannot be used as other functions.
